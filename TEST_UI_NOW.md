## ?? Troubleshooting

**Badge not showing?**
- Check XAML compilation errors
- Verify `statusBadge` is in MainWindow.xaml
- Check `UpdateShaderStatusDisplay()` is called

**DLL indicator not showing?**
- DLL might not be present (this is OK!)
- Build Native project if you want to test with DLL

**Colors look wrong?**
- This is normal in dark mode (future enhancement)
- Core functionality works regardless
