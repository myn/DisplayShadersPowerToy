## ?? Quick Reference Cards

### Quick Setup Card
```
1. Run DisplayShadersPowerToy.exe
2. Select display type:
   - LG OLED ? WRGB Stripe
   - Samsung OLED ? RGB Triangular
   - LCD ? RGB Stripe
3. Set intensity (70-80% for OLED)
4. Click "Apply"
5. Enable "Start with Windows"
```

### Quick Troubleshooting Card
```
Text blurry? ? Increase intensity
Color fringing? ? Decrease intensity
No change? ? Restart app being tested
Still issues? ? Check FAQ.md
```

### Quick Settings Card
```
LG OLED: WRGB Stripe @ 80%
Samsung OLED: RGB Triangular @ 70%
Standard LCD: RGB Stripe @ 100%
```
